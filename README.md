# 🌿 NutriPlan

Персональный планировщик питания — PWA-приложение с AI-ассистентом.

## Что умеет

- 📅 Дневник питания по дням недели (данные сохраняются на устройстве)
- 🤖 AI-ассистент знает твои предпочтения (без яиц, молочки, белой рыбы)
- 🍫 Быстрая кнопка при гипогликемии
- 📊 Подсчёт калорий, белков, углеводов, жиров
- 📲 Устанавливается на телефон как приложение (PWA)
- 🎯 Пятница автоматически отмечается как чит-дей

## Установка на GitHub Pages

1. Создай репозиторий `nutriplan` на GitHub
2. Загрузи все файлы из этой папки в корень репозитория
3. Перейди в Settings → Pages → Source: `main` branch, папка `/ (root)`
4. Сохрани — через 1-2 минуты сайт будет на `https://ТВО_ЛОГИН.github.io/nutriplan/`

> ⚠️ **Важно:** в файле `sw.js` замени `/nutriplan/` на `/ИМЯ_ТВОЕГО_РЕПОЗИТОРИЯ/` если назовёшь репо иначе.

## Получить API ключ

1. Зайди на [console.anthropic.com](https://console.anthropic.com)
2. Billing → Add credit → пополни на $5
3. API Keys → Create Key → скопируй ключ (`sk-ant-...`)
4. При первом открытии приложения введи ключ — он сохранится на устройстве
